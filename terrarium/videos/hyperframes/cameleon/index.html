La boucle d'outils

Le caméléon

Comment pense un agent IA ?

Un agent travaille en boucle.

Il vise : le modèle réfléchit.

Il lance sa langue : c'est un appel d'outil.

Il ramène sa prise : le résultat de l'outil.

Sa couleur change : le résultat enrichit son contexte.

Puis il recommence. Viser, attraper, avaler.

Il s'arrête quand il n'a plus besoin d'outil.

Dans un agent, c'est la même boucle.

La boucle d'outils

  1. 1Le modèle réfléchit
  2. 2Il demande un outil
  3. 3Le programme exécute l'outil
  4. 4Le résultat revient dans le contexte

… et on recommence, jusqu'à la réponse finale.

En code : une simple boucle.

Dans le code

while (true) {  const r = await modele.generer(messages);  if (!r.appelOutil) return r.texte;  const resultat = await executer(r.appelOutil);  messages.push(resultat);}
